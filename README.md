# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

## 维修回访闭环

- **完工即排期**：事项标记为已完工时，自动安排七天后回访；新建时直接选“已完工”同样生效。
- **延期限制**：每项（每轮）回访只能延期一次，必须填写延期原因，延期后顺延七天。
- **不得重复排期**：上一轮回访未登记结果前，不能再次标记完工，也不会生成新排期。
- **登记结果**：满意即结案（新增“已结案”状态）；不满意必须选择返工原因，事项退回“处理中”，原费用与照片保留在返工历史中。
- **逾期单列**：超过计划回访日未回访的事项，在列表顶部和统计卡中单列；补回访后立即消失。

代码按业务拆分为三个文件，均不接后端、不加依赖：

- `src/followup.js`：回访规则（排期、延期、结案/返工、逾期判定），纯函数；
- `src/storage.js`：localStorage 读写、初始数据与旧数据兼容；
- `src/main.js`：页面渲染与事件接入。
