# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版新增维修回访（纯前端、无新增依赖）：

- 完工即自动安排 7 天后回访；同一事项未回访前不会重复排期。
- 每项回访只能延期一次，延期需填写原因（顺延 7 天）。
- 登记回访：满意即结案；不满意必须选择返工原因，事项退回“处理中”，原费用和照片快照保存在历史记录中。
- 逾期未回访在列表“逾期未回访”筛选与顶部统计中单列；补登记回访后立即消失。
- 代码拆分为三个业务文件：`src/visit/rules.js`（回访规则）、`src/visit/storage.js`（本地存储与迁移）、`src/visit/ui.js`（页面接入）。
